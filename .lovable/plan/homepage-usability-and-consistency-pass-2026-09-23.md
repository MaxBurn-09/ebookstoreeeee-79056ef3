# Homepage usability and consistency pass

## What will change
1. Consolidate homepage typography into a small shared scale and raise all audited labels to at least 12px.
2. Reduce text colors and corner radii to existing semantic roles and a consistent radius set.
3. Standardize homepage actions into primary, secondary, icon, and compact button patterns.
4. Change the long uppercase hero caption to readable sentence case.
5. Make featured covers reliable by using the public optimized cover files as fallbacks and retaining a branded loading state only while images load.
6. Make the sticky browse action smaller and hide it while scrolling down, then restore it while scrolling up.
7. Place Learn, Grow, and Evolve in a clearly aligned grouped panel.
8. Remove the dense location-link block from the footer and retain the dedicated Locations destination.
9. Give hero search and newsletter signup the same field and submit-button treatment.
10. Show purchase notices less often and remember dismissal for the browser session.
11. Smooth the existing three-book carousel with stable keyed positions and opacity/transform transitions, without changing its composition.

## Accessibility and verification
- Preserve labels, keyboard operation, visible focus states, reduced-motion behavior, and meaningful image alternatives.
- Verify cover loading, scrolling behavior, carousel motion, horizontal overflow, and browser errors on desktop and mobile.
- Confirm the homepage still carries its existing page metadata and content hierarchy.
